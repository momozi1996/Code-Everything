# 监控设施与控制权 · AI 原型任务模板

> 来源：https://gameplayatlas.loopyhop.com/mechanic/stealth-security-network/

```text
你是一名资深游戏原型工程师。请用原创代码与原创占位素材，实现一个可玩的最小原型，验证以下机制。不要复制任何现有游戏的名称、角色、世界观、地图、界面布局、数值表、美术、音频或代码。

## 机制
监控设施与控制权（Surveillance control）

## 设计目标
摄像头既能发现你，也能成为你看见敌人的眼睛。

## 基础规则
设施监视一片区域，并可能记录证据或触发警戒。玩家选择绕开、破坏或接管，付出工具、资源或绕路成本；接管后的信息收益与清除记录后的补救收益应分开呈现。

## 核心循环
1. 确认监控覆盖
2. 寻找设备或控制点
3. 绕开、关闭或接管
4. 利用新的安全与情报

## 关键取舍
- 为短暂通过直接破坏摄像头，还是投入更多资源让它持续侦察？
- 已经被录下时，完成目标就走，还是绕去清除记录？

## 可调参数
- 共享控制范围：一个终端控制越多设备，争夺终端越有价值，也越容易成为唯一解。
- 接管成本：成本越高，玩家越要比较情报能否服务于后续路线，而非只看当前房间。

## 最小实现建议
做一台摄像头、一个开关终端与敌方/玩家两种控制状态；同一视野数据切换所有者。

## 验证方式
玩家能否说清接管摄像头带来的新信息，并据此改变下一步路线？

## 需要避免
先别做完整黑客小游戏；让控制权变化确实改变玩家能看到什么。

## 交付要求
1. 先完成可验证的机制闭环，再考虑表现层；范围控制在单局 3–5 分钟。
2. 所有素材必须原创、程序化生成或使用明确的占位符，不使用第三方游戏资产。
3. 提供运行方式、操作说明、关键参数和验证结果。
4. 如果表现与机制验证冲突，优先保留机制，不增加无关系统。
```
