# 灌溉覆盖布局 · Irrigation coverage

> 用占地与建造成本，交换重复浇水的时间。

- **系统**：种植与经营（farming）
- **标签**：spatial, optimization, planning
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/farming-irrigation-layout/)

## 基础规则

玩家把灌溉装置放入田地，让覆盖范围内的作物自动得到水。装置本身占位，覆盖形状与供水条件形成布局约束；漏水地块会暴露设计中的空隙。

## 核心循环

1. 标出种植范围
2. 放置灌溉与供水设施
3. 检查边角覆盖
4. 扩田并重排装置

## 关键取舍

- 最大种植密度不一定便于收获，必须留出通路。
- 先覆盖已有地块还是为扩张预留管线，决定短期与长期成本。

## 可调参数

- **覆盖形状**：十字、方形与圆形会产生不同的留白和拼接问题。
- **供水依赖**：加入水源或水箱后，单点摆放升级为网络规划。

## 最小原型

- **第一步**：做固定网格、一种十字覆盖喷头和干湿两种地块状态，实时显示遗漏数。
- **验证**：给相同数量的喷头，观察玩家能否改位置减少手浇，而不是只能继续买设备。
- **避免**：水压、地下管线与可旋转喷头会增加另一套规则，可在布局本身好玩后再加。
