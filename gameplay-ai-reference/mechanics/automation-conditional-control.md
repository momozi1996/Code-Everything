# 传感器条件控制 · Sensor-driven control

> 让机器根据温度、库存或其他信号自动启停。

- **系统**：自动化与物流（automation）
- **标签**：information, optimization, creativity
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/automation-conditional-control/)

## 基础规则

玩家读取传感器数值，设定阈值或逻辑，再把输出连到设备。条件满足时机器改变状态；观察振荡、延迟或误触发，再调整规则。

## 核心循环

1. 选择要监测的量
2. 设置条件
3. 接线到执行器
4. 制造边界情况并调试

## 关键取舍

- 把启停阈值设得很接近能紧贴目标，但是否会让设备在边界反复开关？
- 只按库存控制，还是再加一个电量条件？多一个条件值得增加多少调试工作？

## 可调参数

- **信号延迟**：延迟增大会让提前量和安全余量变得必要。
- **逻辑复杂度**：简单条件适合入门；组合逻辑支持玩家自制控制器。

## 最小原型

- **第一步**：做一个库存传感器、一个开关设备和可调阈值，持续展示读数与开关原因。
- **验证**：玩家能否通过改变阈值消除来回启停，并说明每次开关由什么触发？
- **避免**：复杂逻辑门和大量传感器会让故障难定位，先保证一条控制链可以逐步追踪。
