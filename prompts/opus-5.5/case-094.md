# Bento 作品集网站

```
Design a bento-grid portfolio for "Mira Okafor — Product Designer" (fictional). Neutral palette: #f5f5f7 page, #ffffff tiles, #1d1d1f text, one vivid lime accent #c3f53c and a deep indigo feature tile #1b1f3b. A responsive bento grid of 10–12 tiles of varied sizes with 24px radii and delicate shadows: an intro tile with name and role; a local-time tile with a live analog clock; a "Now playing" tile with an animated equalizer; a project tile containing a mini animated UI mockup (a CSS-drawn phone screen scrolling); a stats tile with counting numbers; a location tile with a stylised abstract SVG map and a pulsing pin; a tools tile with floating chips; a testimonial tile; a "Currently reading" tile with a CSS book; a contact tile with a magnetic button; and a dark tile with a generative gradient mesh. Interaction: tiles lift and reveal extra detail on hover; a cursor spotlight glides across tile surfaces; clicking a project tile expands it into a full-screen case-study overlay with a smooth shared-element transition. Typography: a system sans with tight tracking.
```
