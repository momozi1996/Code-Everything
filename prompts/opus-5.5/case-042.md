# 蒸汽波未来商场

```
Build "PLAZA AETERNA — Mall of Tomorrow (Est. 1994)", a vaporwave dreamscape. Background: a sunset gradient (#ff71ce → #b967ff → #01cdfe) with a striped retro sun, a 3D-perspective neon grid floor scrolling toward the viewer, palm silhouettes, and a slowly rotating marble bust built from layered SVG shapes with procedurally generated marble veining. Overlay draggable Windows-95-style windows (bevelled grey #c0c0c0, navy title bars) containing: a "Store Directory" with pastel icons, a mock MIDI player that plays a synthesized chord progression (Web Audio, after a gesture), and a "Welcome" message in full-width styling (Ａ Ｅ Ｓ Ｔ Ｈ Ｅ Ｔ Ｉ Ｃ). Typography: a mixture of serif italics, pixel-feeling monospace and widely spaced letters. Interaction: drag windows by their title bars, minimise them to a taskbar with a Start button and clock, click desktop icons to open windows, and a VHS tracking glitch on hover. Responsive: windows become stacked cards on phones.
```
