# 调整速度安排出手先后 · Tune speed to arrange turn order

> 让先手留给铺垫者，再让收割者接上。

- **系统**：指挥与单位（command）
- **标签**：planning, timing
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/command-initiative-order/)

## 基础规则

玩家通过配装、属性或状态改变单位的出手先后，让减防、治疗与攻击按需要衔接。速度不一定增加行动次数；还要看敌我是否交替、每轮是否重排。行动队列或实际出手结果给出反馈。

## 核心循环

1. 观察当前出手顺序
2. 调整关键单位速度
3. 执行铺垫与后续行动
4. 根据敌方先手重新安排

## 关键取舍

- 让治疗者抢先保命，还是让控制者先压住危险敌人？
- 为抢先手牺牲伤害，能否换来少挨一次攻击？

## 可调参数

- **速度随机幅度**：随机越大，精确连招越不稳定，更需要备用计划。
- **重排时点**：每轮重排方便局间调整；实时重排会让加速效果更难预测。

## 最小原型

- **第一步**：做四个单位和一条排序队列，只提供一件改变速度的装备。
- **验证**：玩家能否在开战前说出调整后谁会先动，以及这样做的目的？
- **避免**：别把速度、行动点与行动次数混成一个难读数值。
