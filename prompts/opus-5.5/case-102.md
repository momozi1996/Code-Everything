# 火星任务控制台

```
Create "ARES VII Mission Control", a dashboard for a fictional crewed Mars mission with clearly simulated telemetry. Aesthetic: "NASA-punk" — dark slate panels (#0e1116), safety orange #ff6b1a, off-white #e8e6e3, amber warnings #ffb000, cyan data #4ee1ff, thin grid lines, rounded-rectangle panels with corner brackets and tiny monospace labels. Panels: a mission elapsed time (MET) counter and a countdown to orbit insertion; a trajectory diagram (SVG Hohmann transfer between Earth and Mars with the spacecraft moving along it); live telemetry charts (cabin O₂, CO₂ ppm, power, velocity) as smoothly scrolling line charts; crew status cards with heart-rate waveforms; a comms log whose messages arrive after a one-way light-time delay; a subsystem status grid with nominal/caution/warning lights; and an animated spacecraft schematic. Interaction: click subsystems for detail; an "acknowledge" button when a random caution appears (flashing, with a Web Audio beep after a gesture); a toggle between Earth time and Mars sol time. A responsive grid that collapses gracefully.
```
