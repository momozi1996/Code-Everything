# 视频生成与 DaVinci 调色工作流

```
One tap workflow
Step 1: Upload Reference Image 1 and Reference Image 2.
Step 2: Analyze Image 1 (subject, scene, lighting, composition) using the cinematic-video-prompt format, then write a 10-second storyboard prompt and design non-static, cinematic camera movements.
Step 3: On the @PixVerse platform, select Seedance 2.5 → All-in-One Reference Mode → 1920×1080 → 10s, place Image 1 in the prompt field, and generate.
Step 4: Download the generated video and import it into DaVinci Resolve
Step 5: Do primary grading: color correction (white balance, exposure, contrast, saturation).
Step 6: Do secondary grading: multi-node selective grading (skin, sky, background, subject isolation) + stylization, then fine-tune by referring to Image 2 for silent side-by-side comparison.
Step 7: Render and export to the your local path
```
