# 蓄力后选择放手时机 · Charge, then choose when to release

> 多等一会儿能换强力一击，也可能把安全出手机会等没了。

- **系统**：射击与弹道（projectiles）
- **标签**：timing, risk, precision
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/projectiles-charged-release/)

## 基础规则

按住攻击进入蓄力状态，松开后发射；蓄力改变伤害、射程或其他效果，并通过音效、光效或进度显示。玩家需要估计敌人的接近速度，在快速弱击与等待强击之间选择。

## 核心循环

1. 估计安全等待时间
2. 开始蓄力并保持瞄准
3. 选择时机释放
4. 根据命中和敌人位置再准备

## 关键取舍

- 弱敌是否值得蓄满，还是快速射击更节省暴露时间？
- 快蓄满时目标离开射线，是放弃这次蓄力还是继续追踪？

## 可调参数

- **蓄力收益曲线**：前期就有明显收益便于灵活出手；收益集中在末段会鼓励冒险等满。
- **蓄力时移动限制**：减速越多，蓄力越依赖提前选位；完全自由则更强调跟瞄。

## 最小原型

- **第一步**：先做两档威力、一个接近目标和清楚的蓄满提示。
- **验证**：面对慢目标和突然贴近的目标，玩家会不会主动切换蓄力长度？
- **避免**：如果满蓄力在所有场合都最好，轻射会失去意义。
