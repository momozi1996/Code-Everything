# 无人运输网络 · Autonomous aerial logistics

> 把重复搬运交给飞行单位，再围绕覆盖、能源和吞吐重新规划。

- **系统**：自动化与物流（automation）
- **标签**：planning, spatial, optimization
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/automation-aerial-logistics/)

## 基础规则

玩家设置供给点、需求点与运输设施，让飞行单位搬运物品。覆盖或航线、充能和装卸能力限制效率；运输队列与缺货提示需要扩容的位置。

## 核心循环

1. 建立供需端点
2. 部署飞行运力
3. 补充能源
4. 观察拥堵并扩容

## 关键取舍

- 飞行可以绕开地形，但长距离与频繁小批量可能拖低效率。
- 集中枢纽易管理，分散节点更接近消费者。

## 可调参数

- **单次载量**：载量增大适合大宗运输，载量小会放大往返成本。
- **补能约束**：充能点稀疏会让节点位置比直线距离更关键。

## 最小原型

- **第一步**：用地图节点、固定航程时间和一架带充电状态的运输机，先不用自由飞行寻路。
- **验证**：在远近需求同时出现时，玩家是否能通过改库存或线路减少缺货等待？
- **避免**：大量自主单位、碰撞和动态航线容易带来性能问题，先验证订单分配规则。
