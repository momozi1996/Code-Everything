READ BEFORE YOU RUN

不缩写题目，也不制造答案。

01 / 复制的是什么

Prompt 列原文在前，空一行后接完整“原始题目”列。无标题、评价或额外指令。公式保留原始 LaTeX；段落转换为换行，忽略空白排版段。

02 / 这是研究测试集

并非一道题就有唯一、现成的答案。详情保留来源表中的难度、可能的评测方案、GT 标注与验证，以及是否已被解决的说明。

03 / 把边界留在视野内

未执行任何 Prompt，也没有评判模型是否攻克。医学与生物题用于研究和评测，不替代临床判断、伦理审查或专业验证。
