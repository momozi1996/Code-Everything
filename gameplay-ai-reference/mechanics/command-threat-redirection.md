# 把敌人的注意力拉到自己身上 · Redirect enemy attention

> 让能承伤的人接管危险，给脆弱队友腾出空间。

- **系统**：指挥与单位（command）
- **标签**：cooperation, planning
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/command-threat-redirection/)

## 基础规则

敌人按威胁或目标规则选择攻击对象，玩家用嘲讽、挑衅或其他手段改变这个选择。拉住敌人后还要安排距离、防护和治疗；目标指示线或转身动作说明谁正在承压。

## 核心循环

1. 发现脆弱队友被盯上
2. 让承伤单位提高威胁
3. 承接攻击并稳住位置
4. 检查目标是否再次转移

## 关键取舍

- 把所有敌人拉来可能保护队友，也可能超过自己的承伤能力。
- 立即拉走敌人，还是等队友用完位移后再接手？

## 可调参数

- **威胁持续时间**：持续短需要反复维护，持续长则更依赖一次正确选人。
- **目标切换提示**：明确显示目标变化，让玩家能判断保护是否生效。

## 最小原型

- **第一步**：做两个友方单位、两个敌人和一种强制换目标效果。
- **验证**：玩家是否能看出敌人换了目标，并据此移动或治疗？
- **避免**：别让嘲讽变成永远安全的按钮；承伤与位置要产生后果。
