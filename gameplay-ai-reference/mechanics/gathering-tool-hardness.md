# 采集工具门槛 · Harvesting tool gates

> 看得到的资源，不一定能用现在的工具带走。

- **系统**：采集与挖掘（gathering）
- **标签**：progression, planning, discovery
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/gathering-tool-hardness/)

## 基础规则

矿物或植物要求特定工具类别或等级，低级工具无法采得有效材料。玩家记录位置、取得升级材料再回来，成功开采反馈工具升级的实际价值。

## 核心循环

1. 发现新资源
2. 检查工具要求
3. 升级或更换工具
4. 返回开采

## 关键取舍

- 现在为升级绕路，还是先采现有工具能处理的资源？
- 新工具先服务哪条装备或建筑路线？

## 可调参数

- **门槛跨度**：跨度大让升级更有冲击力，也可能造成长时间空转。
- **失败反馈**：明确提示缺少工具减少无效敲击；只显示零伤害容易误导。

## 最小原型

- **第一步**：做两种工具和两种矿点，显示不能开采的原因，并允许标记位置。
- **验证**：玩家遇到不可采矿点后，是否能自行找到升级目标并愿意回来？
- **避免**：工具层级太多会造成反复刷同样材料；先让每次升级带来清楚的新用途。
