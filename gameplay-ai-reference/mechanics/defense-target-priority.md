# 设置自动攻击优先级 · Set automatic target priorities

> 塔会自己开火，玩家决定它先解决哪一种威胁。

- **系统**：防御与阵地（defense）
- **标签**：information, planning, optimization
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/defense-target-priority/)

## 基础规则

玩家为防御单位选择目标规则，例如优先打最前面的敌人或最强的敌人。规则持续生效，直到玩家更改；射线、目标标记和漏怪结果帮助判断分工。目标选择仍受射程、攻击类型和是否能发现目标限制。

## 核心循环

1. 观察队列里的不同威胁
2. 给塔设置目标规则
3. 查看火力实际分配
4. 按漏怪情况调整分工

## 关键取舍

- 先清掉出口前的小怪，还是让重火力持续打高血量敌人？
- 所有塔打同一个强敌可能浪费伤害，分工又可能让强敌活着走出射程。

## 可调参数

- **切换成本**：免费切换鼓励临场指挥；有冷却时更重视波次前的判断。
- **优先级种类**：先给少量能看出差异的规则，过多细分会增加理解和操作负担。

## 最小原型

- **第一步**：先做一条路、两座塔和“最前/最高血量”两个规则。
- **验证**：同一布局只换优先级，玩家能否预测哪类敌人更容易漏掉？
- **避免**：目标标记和射程必须清楚，否则玩家会以为塔没有听指令。
