# 造迷宫延长敌人路线 · Build a longer enemy route

> 花有限的建筑资源，让敌人多走几步、多挨几轮攻击。

- **系统**：防御与阵地（defense）
- **标签**：spatial, planning, optimization
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/defense-maze-routing/)

## 基础规则

玩家在允许建造的地面放置障碍或防御塔，改变地面敌人前往目标的路线。既要留下可通行的道路，又要让敌人尽量多次经过火力覆盖区；路径预览和实际行军轨迹告诉玩家布局是否有效。

## 核心循环

1. 查看入口与出口
2. 放障碍拉长路线
3. 让敌人经过火力区
4. 根据漏怪位置改布局

## 关键取舍

- 用钱增加路程，还是直接买火力？路再长，伤害不足也守不住。
- 把所有敌人汇到一个窄口很省塔，但也更依赖这一个位置。

## 可调参数

- **障碍成本**：成本低时鼓励反复改路；成本高时每个拐弯都要证明价值。
- **允许的通路宽度**：宽通路减少极端绕路，更强调火力覆盖；窄通路更强调迷宫布局。

## 最小原型

- **第一步**：用二维方格、一个入口、一个出口、两种建筑做出可预览的寻路。
- **验证**：测试者能否说清一块墙为何值得放在这里，并根据漏怪主动改路？
- **避免**：先不做多层地图和飞行敌人；必须先处理彻底堵路时的反馈。
