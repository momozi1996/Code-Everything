## Prompt

```
Build "RASTER — Swiss Poster Machine", an homage to the International Typographic Style. The page is a single poster on an off-white (#f2efe8) sheet set on a strict 12-column modular grid (revealable with the G key or a toggle that shows hairline cyan grid lines). Palette strictly signal red #e30613, black #111 and white. A heavy grotesque sans stack ("Helvetica Neue", Helvetica, Arial, "Nimbus Sans", sans-serif) used with extreme scale contrast: a giant numeral or word, small flush-left body text, rotated captions. Geometric elements (circles, bars, quarter-arcs) occupy grid cells. Every click (or Space) recomposes the poster from a new seed — elements slide and rotate to new cells with crisp eased FLIP-style transitions, never overlapping text illegibly. Show the seed as an edition mark ("No. 0417"). A small control strip: previous/next composition, grid toggle, invert (black ground). It must look like a museum-quality, Müller-Brockmann-inspired print at any viewport, reflowing the grid for portrait phones.
```
