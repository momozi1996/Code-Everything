# 战斗牌库循环 · Combat draw–discard cycles

> 每次出牌既解决眼前问题，也改变下一轮抽牌结构。

- **系统**：战斗与战术（combat）
- **标签**：planning, randomness, optimization
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/combat-combat-deck-cycle/)

## 基础规则

从牌库抽取手牌，在能量限制内出牌；使用或未保留的牌进入弃牌区。抽牌堆耗尽后弃牌堆重新洗入，玩家通过过牌、保留和移除改变关键牌出现的频率。

## 核心循环

1. 查看手牌与敌情
2. 分配能量与出牌顺序
3. 弃牌并结束回合
4. 抽取或重洗下一手

## 关键取舍

- 本回合防守与快速过牌冲突：能否承受一点伤害换下一手关键组合？
- 一张强牌只有被抽到才有价值，精简与冗余各有代价。

## 可调参数

- **手牌与能量比**：牌多能量少强调取舍，能量宽松则强调排序。
- **重洗节奏**：小牌库更稳定，大牌库更需要搜索与冗余。

## 最小原型

- **第一步**：做十张固定卡、一名显示意图的敌人、抽牌堆与弃牌堆。
- **验证**：观察玩家是否会为了下一轮少打一张牌，并能解释抽牌堆与弃牌堆的区别。
- **避免**：先确认抽牌、弃牌、洗牌的时序；特殊效果太早加入会掩盖循环问题。
