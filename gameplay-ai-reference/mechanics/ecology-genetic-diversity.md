# 保留不同血缘与基因 · Preserve genetic diversity

> 只留下最优秀的一家，可能让后续配对越来越困难。

- **系统**：生态与系统（ecology）
- **标签**：planning, information, progression
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/ecology-genetic-diversity/)

## 基础规则

种群不仅需要当前强壮个体，还需要可持续配对的差异。玩家检查亲缘或关键基因，保留不同来源的成员，并在短期表现与长期繁殖选择之间取舍。

## 核心循环

1. 查看现有血缘与关键基因
2. 找出过度集中或冲突的组合
3. 保留外来或少见个体
4. 在下一代重新检查配对空间

## 关键取舍

- 引入数值普通但血缘不同的个体，还是继续繁殖现有优秀家族？
- 空间不足时保留少见基因，还是优先留下当前贡献最大的成员？

## 可调参数

- **重复基因的后果**：后果应可提前推断，不能到出生后才给出无从避免的惩罚。
- **外来个体获得成本**：外来来源越难获得，保留现有多样性的长期价值越高。

## 最小原型

- **第一步**：先用三种可见基因标记和有限栏位，明确提示哪种配对有风险。
- **验证**：给一只数值较弱的外来个体，看玩家是否因未来配对价值主动保留它。
- **避免**：家谱会迅速变成信息负担；先做两代关系和直接配对提示。
