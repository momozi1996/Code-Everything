# 雷达与声呐控制台

```
Create "SENTINEL — Radar Array", a radar/sonar console as polished UI art, set in a clearly fictional scenario. Phosphor green (#39ff88) on dark olive-black (#020a05), with an amber mode. The centrepiece: a circular PPI radar scope on canvas with range rings, bearing ticks (0–359°), a rotating sweep beam with a fading afterglow wedge, and contacts (blips) that brighten when swept and then decay; contacts move along plausible tracks (aircraft, ships, a fast unknown), each with a small data tag (ID, heading, speed, altitude) and a trail of past positions. Surrounding console panels: a contact table, a signal-strength waterfall/spectrogram, system status indicators, a compass heading readout and a scrolling event log. Interaction: click a contact to lock on (target reticle, detailed readout); a range selector (10/25/50 nm) that rescales smoothly; a radar/sonar toggle — sonar switches to a blue-green water palette with pings and a Web Audio ping sound after a gesture. Typography: monospace with stencilled headings.
```
