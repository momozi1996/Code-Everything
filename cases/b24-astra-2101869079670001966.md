## Prompt

```
「すごろく」を作りたいです。現存するすごろくについてさまざまなゲーム性をリサーチし、小学生でも遊べる、簡単でシンプルだけどさまざまな体験ができる「すごろく」にしてください。

マスは小さすぎず、4人のプレイヤーがコマを使って遊べるサイズ感にしてください。

・世界観：
RPG風の冒険感満載の「すごろく」。絵柄は実際のRPGのように精細に描き込み、場面ごとのムードを特徴付けて描画してください。

・A4横サイズを4枚並べてつなげて、A2サイズの盤面にする
・内蔵ImageGenで描画して4枚の高解像度ファイルとして出力する
・すごろく内の随所にサイコロをつかったイベントを8種類用意し、それぞれ違った工夫をほどこす
・スライム、キメラ、ゴブリン、オーク、トロール、ケンタウロス、ドラゴンなどRPG定番のモンスターに加え、ギリシャ神話や北欧神話の怪物も登場させる
・天使や女神や妖精、武器屋や鍛冶屋や宿屋、村人や踊り子やダンサーなど、自分を助ける存在も随所に配置する

・上記に加え、「添付画像」を元に以下の登場キャラクターを最重要イベントとして配置する。添付画像の顔の特徴を損なわないように似せ、衣装や風貌をゲームのテイストに合わせてキャラクター化する。添付画像のファイル名の番号は下記のキャラ番号と一致している。

①魔女「ママの名前」：プレイヤーを振り出しに戻す魔法をかけたり、逆に有利になる魔法をかける

②伝説の勇者「息子の名前」：プレイヤーを有利にする何かを授けてくれる

③妖精「娘の名前」：気まぐれな妖精で、思いもつかない悪戯をプレイヤーにしかける

④ラスボス「パパの名前」：ラスボス。6本の腕にそれぞれ特殊な武器を構えている。

・ゲーム性として必要であれば「カード」を別途作成する。その場合はA4にカード画像を並べて出力する。（こちらで切り分けて使用します）

・ゲーム盤面とは別に、このゲームのルールを基本から「小学生にもわかるように」A4横サイズ1枚にまとめてください。ゲーム本編に合わせたテイストで、ワクワクするようなビジュアルで。中央にゲームのタイトルを大きく描画してください。

・上記の完成を確認後、プレイヤーのコマを8つ作ります。 15mm×35mmの枠を4つ横につなげてそれぞれの枠内にキャラ（正面・左横・背面・右横）を描き込み、出力後にそれを折って繋げて四角柱にします。天面と底面は不要です。 これを下記の8パターンのキャラで描いてください。
人間の少年戦士、少女魔法使い、男性格闘家、女性僧侶、女エルフ、獣人（男）、獣人（女）、老賢者
```
