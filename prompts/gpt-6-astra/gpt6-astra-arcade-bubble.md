# 泡泡连锁爆破对抗

```
用原生 JavaScript ES 模块和 Canvas 2D 制作原创复古同屏双人游戏《泡泡爆破》，不要复制现有游戏角色或素材。960×600 水族馆画布，11×9 地图，固定墙、随机可破坏箱子、透明彩色泡泡、带潜水镜和表情的小鱼角色。出生走廊与外圈始终连通。方向键移动，每格约 0.14 秒；动作键放泡泡，2.1 秒后十字爆破，墙挡住，箱子挡住并破坏，可连锁引爆。初始容量 1、范围 2，可通过道具提升。破箱 +4、道具 +3、回合存活胜方 +40；同时被炸不加回合分；75 秒总分判胜，自动重开小回合。副动作开启 0.75 秒护盾，冷却 7 秒。实现键盘和手机方向键、同屏双人和真实规划逃生的非作弊机器人，明确展示模式。种子确定性、结束冻结、计分真实。绘制泡泡折射渐变、爆破光环、粒子、角色游动等动态画面。测试碰撞、出生逃生、容量、离开泡泡不能重入、十字阻挡、连锁爆破、盾、计分和平局。
```
