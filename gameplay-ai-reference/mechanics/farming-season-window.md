# 季节种植窗口 · Seasonal planting windows

> 让收成的截止日期，比种子价格更值得考虑。

- **系统**：种植与经营（farming）
- **标签**：planning, time, economy
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/farming-season-window/)

## 基础规则

玩家根据当前季节和剩余天数选择作物。作物需要在适宜季节完成成长；跨季后无法继续的作物会失去后续收益，因此播种前必须倒排收获日期。

## 核心循环

1. 查看季节与剩余天数
2. 计算能完成的收获次数
3. 买种并播种
4. 季末收获或换种

## 关键取舍

- 高价长周期作物未必适合季末；短周期作物能填补空档。
- 多季作物减少换季损失，但可能占用下一季更有利的土地。

## 可调参数

- **季节长度**：短季节要求精确规划，长季节允许更松弛的经营。
- **跨季惩罚**：枯萎制造明确截止线；仅减产则鼓励承担风险。

## 最小原型

- **第一步**：做一张10天日历和两种成长时长不同的作物，让玩家预览收获日期。
- **验证**：改变剩余天数，检查玩家是否会换作物，并能说出“这批赶不上收获”。
- **避免**：不要一开始叠加天气、病害和多季节例外，否则很难判断玩家算错在哪里。
