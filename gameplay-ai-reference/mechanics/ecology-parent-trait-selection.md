# 挑选亲本保留后代性状 · Select parents for offspring traits

> 繁殖之前看双方特点，繁殖之后检查哪些特点传给了下一代。

- **系统**：生态与系统（ecology）
- **标签**：planning, randomness, progression
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/ecology-parent-trait-selection/)

## 基础规则

玩家根据目标选择一对亲本，后代按公开或可研究的遗传规则获得性状。结果通常有不确定性，玩家要决定留下谁继续繁殖，而不是只让数量增加。

## 核心循环

1. 确定需要的后代特点
2. 比较并配对亲本
3. 检查后代的实际结果
4. 留下合适个体进行下一代

## 关键取舍

- 选当前数值最高的两个，还是选特点互补的一对？
- 已有合适后代时停止，还是继续繁殖争取稀有组合？

## 可调参数

- **遗传信息可见度**：只显示外观会鼓励试验；显示潜在基因能支持更明确的配对推理。
- **育种占用成本**：后代占用空间和照料资源，才能让“再试一次”成为真实选择。

## 最小原型

- **第一步**：用两项性状、三个亲本和一个可解释的遗传表做三代实验。
- **验证**：让玩家连续选择两代亲本，看其能否依据后代结果修改下一次配对。
- **避免**：不要先做几十种外观和复杂家谱；先让配对能改变后代选择。
