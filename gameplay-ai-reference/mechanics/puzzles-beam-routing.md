# 光束路径与接收器 · Routing beams to receivers

> 移动少量中继物，让整条能量路径成立。

- **系统**：解谜与推理（puzzles）
- **标签**：spatial, optimization, planning
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/puzzles-beam-routing/)

## 基础规则

光束需要到达指定接收器才能打开通路。玩家调整中继、反射物或传送路径，避免遮挡，并检查多个接收器是否需要同时满足；可见光线让错误容易定位。

## 核心循环

1. 定位光源与接收器
2. 摆放中继或反射物
3. 检查遮挡与连接
4. 通电后穿过通路

## 关键取舍

- 中继应靠近光源，还是能看到多个目标的交汇点？
- 拿走中继后，门会不会把自己关住？

## 可调参数

- **同时目标数**：多目标同时开启要求网络规划；依次开启偏路线题。
- **遮挡规则**：角色可挡光会增加时机与协作；否则更偏静态推理。

## 最小原型

- **第一步**：在二维格子上实现一个光源、两个可旋转反射器与一个接收器。
- **验证**：光路断开时，玩家能否指出具体断点并只移动必要的物体。
- **避免**：先别增加颜色混合与动态遮挡；基础光路必须能被一眼追踪。
