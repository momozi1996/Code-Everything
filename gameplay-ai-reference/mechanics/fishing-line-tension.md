# 收线与张力控制 · Line tension control

> 在鱼挣扎时松手，在停顿时回收距离。

- **系统**：钓鱼与捕捉（fishing）
- **标签**：risk, timing, precision
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/fishing-line-tension/)

## 基础规则

玩家交替收线和放松，以缩短鱼与岸边的距离，同时避免鱼线张力超过上限。持续猛拉可能断线，放手过久则丢失进度；距离与张力反馈让风险始终可读。

## 核心循环

1. 观察鱼是否挣扎
2. 平静时收线
3. 张力升高时松开
4. 重复直到拉近鱼

## 关键取舍

- 再多收一点能更快拉近鱼，但是否还有余量承受下一次突然挣扎？
- 鱼刚平静下来，是立刻收线追进度，还是继续松手把张力降得更低？

## 可调参数

- **张力恢复速度**：恢复快允许短促冲刺，恢复慢要求更保守节奏。
- **挣扎规律**：固定节奏可学习，随机变化则强调读反馈。

## 最小原型

- **第一步**：用距离与张力两条数值、鱼的平静／挣扎两态和收线按钮即可验证。
- **验证**：检查玩家是否主动在危险前松手，以及更熟悉鱼后能否更快完成捕获。
- **避免**：若张力变化全靠随机且没有预兆，松手会变成猜测；先做清楚的行为反馈。
