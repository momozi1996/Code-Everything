## Prompt

```
请直接制作一个可以在浏览器中实时交互的高完成度 3D 城市景观网页。

主题：《清明上河图》里的北宋东京（汴京）——汴河、虹桥与城门内外的街市。
使用 HTML、CSS、JavaScript 实现。不要生成图片，不要只给设计方案，
不要用《清明上河图》图片加视差效果冒充 3D。我要的是实际可运行、可游览的成品。

【一、作品定位】

把《清明上河图》里的汴京，重建成一座可以走进去看的立体城市：
汴河贯穿画面，虹桥横跨河面，两岸的店铺、码头、船只、人群和车马，
组成一座正在运转的城市。

这是一片完整、连续、有远近层次的城市景观，
不是悬浮岛、带底座的沙盘、博物馆模型或孤立的建筑展示，也不是单纯的技术演示。

风格是写实方向的风格化复原：
真实的建筑尺度、材质质感和自然光照，观感接近历史纪录片里的 CG 复原场景；
几何采用程序化建模能做好的干净形体，靠比例、构件层次、材质差异和光影取胜，
不追求照片级写实。
不要低分辨率像素风、粗糙积木、灰白模型和塑料质感，
也不要用古画滤镜或描边掩盖建模质量。

视觉质量优先。宁可少几个功能，也不要牺牲构图、材质和光照。
时间或输出长度有限时，按以下顺序保证完成度：
1. 默认全景画面的完整度与美感；
2. 虹桥与汴河的核心场景；
3. 四个镜头、展卷巡游和三种氛围；
4. 人物、船只和车马的动态；
5. 自由漫游、环境音等其他增强。

历史细节服务于最终画面。考据完整度、模型数量和视觉完成度冲突时，
优先保证默认镜头里虹桥、汴河、船只、建筑群、人流、纵深和光照的质量；
镜头和巡游路线都看不到的区域可以从简，
不要把整座城市做成一堆低完成度模型的集合。

【二、《清明上河图》的参考方式】

先理解原画的空间叙事。长卷从右向左展开：
郊野（疏林薄雾、茅舍、驮炭进城的驴队）
→ 汴河（首尾相接的漕船、码头装卸、纤夫拉纤）
→ 虹桥（全画最紧张热闹的地方：大船过桥，桥上人头攒动）
→ 城门内外的街市（酒楼、店铺、车马和出城的驼队）。
建筑、人流和商业由疏到密，在虹桥和城门一带达到高潮。

借鉴它的空间结构、时代气质、生活密度和叙事节奏。
为了 3D 游览，可以重新设计河道转折、街道尺度和建筑位置，
不要把原画逐段硬搬成立体模型。

原画只是历史与构图参考。即使附有原画图像，也不能用作网页背景或贴图素材，
场景必须由真实 3D 几何、材质和光照构成。

历史分寸以北宋晚期为准：
场景里不要出现玻璃、现代灯具、现代字体、现代服装、现代车辆和现代桥梁结构；
缺少史料的细节，选择符合北宋技术条件与审美的合理设计。

【三、场景构图】

默认打开时就应呈现一幅完整、有吸引力的画面，
不需要用户先旋转镜头才能找到好看的角度。

采用透视相机。默认视角接近原画的斜俯视：
像站在临河的高楼上，沿汴河望向虹桥和远处的城门。
不要沙盘式等距俯视，也不要高到让城市缩成模型。

前景：
河岸、石阶、木桩码头、垂柳、停靠的小船和堆放的货物。
可以用近处的屋檐、酒旗或柳枝形成自然框景，但不能挡住虹桥和河道。

中景：
汴河斜向伸入画面，是视线的主引导线；虹桥横跨河面，是整幅画面的视觉中心。
桥两端连着街市，两岸是茶坊、酒楼、客店、杂货铺、仓库和民居，
建筑之间有真实的街巷和通行关系。
地面有高低、岸线和自然过渡，不是在平面上整齐摆放模型。

远景：
街道通向城门，城楼之后是层层叠叠的屋顶，再远是郊外的树林、村落和地平线。
开封地处平原，不要硬加大山。
用尺度变化、遮挡、冷暖变化和空气透视表现距离，而不是仅仅把远处物体缩小。

默认画面里应一眼看到：
贯穿画面的汴河，横跨河面的虹桥和桥上的人流，正要过桥的大船，
两岸林立的店铺和码头装卸，通向城门的街道，远处密集的屋顶。

疏密要有节奏：郊野稀疏，码头以装卸为主，虹桥和城门街市最密，小巷和民居安静。
郊野和城内两端可以比虹桥一带简略。
不要把所有元素均匀铺满，需要主次、疏密、留白和清楚的视觉焦点。

【四、虹桥与汴河】

虹桥是全作品最重要的地标，需要重点制作。

结构：
按北宋木拱桥的做法。《东京梦华录》记载它"其桥无柱，皆以巨木虚架"：
单跨，河中没有桥墩，由多组长木纵横穿插、相互承托成拱，拱形饱满如虹；
桥面有坡度，两侧有栏杆，桥头连着摊棚和街市。
木构件的穿插关系要看得清。桥身以木色为主，可带旧化的暗红涂饰，
不要做成鲜红的日式拱桥或现代景观桥。

桥上：
挑担的、推车的、牵驴的、摆摊的、倚着栏杆看河的，人流从两端涌向桥顶。

原画最著名的情节：
一艘大船正要穿过桥洞，船工撑篙、用长竿抵住桥身，几个人忙着放倒桅杆；
邻船和岸上的人指点吆喝，桥上的人探身张望。
动作自然克制，不要做成灾难场面。可以做成缓慢循环的动画，静态定格也可以。

汴河：
汴河长期受黄河水源和泥沙影响，水体应有自然的浑浊感，
以土黄、灰绿、黄绿之间的低饱和颜色为主，随天空、水深和反射变化；
不要做成清澈透明的湖蓝色。
水面能映出天空、桥、船和两岸房屋，有缓慢流动、轻微波纹和岸边过渡。
尽量使用实际场景反射；需要性能降级时也应保持视觉可信。
不要用闪烁噪声、强烈扭曲或一整块平面色代替水。

船只：
漕船、货船、客船和小舟，大小和形制各不相同。
大船要看得出木船体、船篷、桅杆、绳索、舵和船工。
有的停靠码头装卸，有的在河中缓缓行驶，岸边可以有纤夫拉纤。

河岸：
石砌驳岸与土岸交替，有木桩、石阶、货堆和搬运工，岸边有湿润的泥土和杂草过渡。

【五、建筑与街市】

建筑要一眼看出是北宋，而不是明清宫殿或影视城：
灰瓦屋面，屋顶坡度比明清平缓，出檐深远，翼角起翘柔和；
以木构梁柱、木门窗和窗格为主，墙体用夯土、青砖或白墙；
斗拱主要用在城楼这类高等级建筑上，普通店铺和民居做法简朴；
城门有厚重的城台和城楼；门洞参考原画和《营造法式》的过梁式木构门道：
两侧立排叉柱，上部木梁承托，顶部中平、两角斜折，整体略呈梯形，
不要做成明清常见的半圆砖石券拱门；郊野有茅草顶的农舍。
避免大红柱子、黄色琉璃瓦、夸张飞檐、满街红灯笼和整齐划一的仿古街。

街市：
大酒楼（正店）和小酒店（脚店）门前搭"彩楼欢门"——竹木扎成、挂着彩帛的门楼架子，
再挂上酒旗。城门内可以用一座这样的大酒楼作为街市焦点（原画中的"孙羊正店"）。
其他店铺用布幌、招牌、遮阳棚和沿街摊位区分经营内容：
茶坊、肉铺、药铺、香铺、布庄、杂货、客店等。
招牌文字可以用 Canvas 生成（如"正店""新酒""脚店"），用楷体一类的书法字体，
不要现代无衬线字体。

体量：
正店酒楼可以两三层；普通店铺和住宅一两层；码头仓库粗犷；城楼最厚重。
不同建筑在宽度、高度、屋顶形态、门窗和招牌上自然变化，
不要复制同一栋房子铺满街道。屋顶要有瓦垄层次，不要用一整块灰色平面。

街道与地面：
主街宽、巷子窄，地面以夯土和石板为主；常走的地方有车辙、磨损和色差，河边略潮湿。
避免棋盘格、规律条纹、重复贴图和明显的程序生成痕迹。

植被：
以柳、榆、槐为主。河边垂柳要有自然下垂的枝条，清明时节新柳嫩绿，郊野有些树刚刚发芽。
树干有转折、分叉和粗细变化，不要做成几个规则球体。
植被是点缀，不要把城市做成森林。

【六、人物与城市生活】

人物决定这座城市有没有生命，也是程序化建模最容易露怯的地方。

造型：
比例正确、不刻画五官的简洁风格化人物，以中远景观看为主。
靠服饰轮廓、头饰、姿态和颜色区分身份：士人长衫、劳力短褐、幞头、斗笠、挑担、背篓。
颜色以灰、褐、青、蓝、米白、暗红、土黄等低饱和色为主，不要所有人同一种颜色。
不要胶囊人、火柴人。

动作：
走路、挑担、推车、搬货、撑船、拉纤、牵牲口、坐着喝茶、驻足交谈和看货。
不需要复杂 AI，简单的循环动画和沿路径移动即可，
但人物不能悬浮、陷进地面或穿过建筑。

车马与牲畜：
驴、马、牛、骆驼，牛车、驴车、独轮车和轿子。
原画里有一队骆驼正从城门洞里走出来，可以作为城门场景的亮点；
郊野路上可以有踏青扫墓归来、轿顶插着柳枝的轿子。

数量：
视觉上要有繁华汴京的规模感。近景和中景重点做约 80 至 150 个可辨识的人物，
远处用实例化的低细节人物补足到数百人的密度。
人物质量和分布节奏优先于实际数量；不要把街道堵死，按前面的疏密节奏分布。

生活细节：
酒旗、布幌、摊棚、箩筐、木桶、麻袋、陶罐、柴担、鱼篓、桌凳、茶具，
少量狗、鸡、鸭和飞鸟。
细节服务于生活氛围，不要为了宣称模型数量而堆砌，让画面显得杂乱。

【七、色彩、光照与氛围】

默认是清明时节的上午：
柔和的阳光，淡蓝的天空，轻薄的晨雾；空气清透，但远处有空气透视。
整体色调沉静自然：木色、灰瓦、青砖、土黄街道、浑黄偏绿的河水、嫩绿新柳，
建筑和人物保持低到中等饱和度。
阳光落在屋顶、桥面和人物身上形成温暖亮部，阴影略偏冷。

需要柔和阴影、环境光遮蔽或接触阴影、合理曝光、克制的泛光、
抗锯齿和有距离层次的薄雾。
避免发白、灰蒙、过度饱和、过度 HDR、满屏浓雾和明显锯齿，
也不要让所有建筑都泛黄发橙。

另提供两种氛围：
黄昏华灯：低角度暖色夕照，天空由暖转冷，酒楼、店铺和桥头陆续亮灯；
暖光集中在有人活动的地方，不要把整座城染成橙色。
清明春雨：阴天和雨丝，屋面和地面颜色变深，路面轻微反光，
河面出现雨点涟漪，雾气加重；有余力时让部分行人撑伞或躲到屋檐下。

切换时应同步改变天空、日光、环境光、阴影、雾、水面和局部灯光或雨效，
不是仅仅修改背景颜色。

【八、镜头与交互】

提供四个经过设计的镜头，切换平滑，每个镜头都要有独立的构图价值：
1. 汴河全景（默认）：高处斜俯视，汴河、虹桥、两岸街市和远处城门同在画面中。
2. 虹桥河岸：低机位站在岸边，仰看虹桥，大船正从桥下经过。
3. 虹桥桥上：略高于人群头顶，看桥上人流、摊贩和桥下河面。
4. 城门街市：从城外街道望向城门，道路、人群、驼队和两侧店铺形成纵深。

展卷巡游（本题特色）：
一键开始，镜头以接近原画的斜俯视角度，从郊野沿汴河缓缓平移，
经过码头、虹桥和街市，穿过城门后停在城内街口，像展开一幅长卷。
任何操作都能打断巡游。

基础交互：
鼠标拖动观察、滚轮缩放或前进，触屏支持拖动和双指缩放。
提供重置视角、隐藏界面和保存当前画面的功能。

可选增强：
WASD 自由漫游，限制在场景范围和合理高度内，不能钻进地下、建筑内部或穿墙；
环境音：河水、风声、橹声、木船碰撞、鸟鸣，以及经过滤波、听不清内容的街市底噪，
用 Web Audio 程序生成，不要尝试合成清晰的人声、叫卖或电子音效；
默认关闭，只在用户主动点击后播放。
额外功能不能影响默认画面的完成度。

界面：
克制、有宋代审美的现代设计，景观是绝对主体。
可以用宣纸色、墨色、朱砂红、石青作点缀；标题如"清明上河 · 汴京"放在边缘；
镜头导航可以设计成一条横向的迷你长卷。
不要做成游戏 HUD，不要在画面中央堆按钮，不要铺满古风花纹。
桌面和手机都不能出现按钮越界、文字重叠或无法操作的问题。

【九、工程与性能】

允许使用 Three.js / WebGL，以及版本固定、互相兼容的 CDN 依赖。
优先使用成熟渲染能力，不要为了"零依赖"重写整套引擎。

自写的 HTML、CSS、JavaScript 尽量整理在一个 HTML 文件中。
景物由程序化几何、Canvas 纹理和材质生成，
不依赖外部图片、3D 模型或音频文件，也不使用原画图片。

人物、树木、瓦片、船只、货物等重复物体使用实例化绘制，复用几何和材质，
远处物体适当简化；合理控制阴影、反射、后期和渲染分辨率。
提供高画质和轻量模式，手机默认使用轻量设置；
普通笔记本上默认设置应保持流畅（约 30 帧以上）。
不要靠无限增加模型数量换取细节。

加入加载提示、WebGL 不支持时的提示和必要的错误处理。
没有开启声音时不要自动播放；尊重减少动态效果的系统偏好。

【十、交付前验收】

不要写完代码就立即交付。

如果当前环境支持浏览器运行和截图，请先实际打开页面，
检查默认镜头、四个镜头、展卷巡游、三种氛围、桌面和手机布局，
再根据截图修正明显的构图、曝光、遮挡、比例和渲染问题。

重点检查：
是否存在空白画面、加载失败、控制台错误；
默认画面是否一眼看出汴河、虹桥和城市，而不是小型沙盘；
虹桥是否是视觉中心，河中有没有桥墩；
人物与门窗、桥栏、船只的比例是否合理，有没有悬浮、陷地、穿模；
有没有明清化、影视城化或现代元素；
是否有闪烁、阴影条纹、过曝、雾太重、水面异常；
远景是否空旷，街市是否整齐得像复制粘贴；
功能按钮是否实际可用，移动端是否越界。

可以使用浏览器截图验收，但不要调用图像生成工具。
```
