# 把敌人的注意力拉到自己身上 · AI 原型任务模板

> 来源：https://gameplayatlas.loopyhop.com/mechanic/command-threat-redirection/

```text
你是一名资深游戏原型工程师。请用原创代码与原创占位素材，实现一个可玩的最小原型，验证以下机制。不要复制任何现有游戏的名称、角色、世界观、地图、界面布局、数值表、美术、音频或代码。

## 机制
把敌人的注意力拉到自己身上（Redirect enemy attention）

## 设计目标
让能承伤的人接管危险，给脆弱队友腾出空间。

## 基础规则
敌人按威胁或目标规则选择攻击对象，玩家用嘲讽、挑衅或其他手段改变这个选择。拉住敌人后还要安排距离、防护和治疗；目标指示线或转身动作说明谁正在承压。

## 核心循环
1. 发现脆弱队友被盯上
2. 让承伤单位提高威胁
3. 承接攻击并稳住位置
4. 检查目标是否再次转移

## 关键取舍
- 把所有敌人拉来可能保护队友，也可能超过自己的承伤能力。
- 立即拉走敌人，还是等队友用完位移后再接手？

## 可调参数
- 威胁持续时间：持续短需要反复维护，持续长则更依赖一次正确选人。
- 目标切换提示：明确显示目标变化，让玩家能判断保护是否生效。

## 最小实现建议
做两个友方单位、两个敌人和一种强制换目标效果。

## 验证方式
玩家是否能看出敌人换了目标，并据此移动或治疗？

## 需要避免
别让嘲讽变成永远安全的按钮；承伤与位置要产生后果。

## 交付要求
1. 先完成可验证的机制闭环，再考虑表现层；范围控制在单局 3–5 分钟。
2. 所有素材必须原创、程序化生成或使用明确的占位符，不使用第三方游戏资产。
3. 提供运行方式、操作说明、关键参数和验证结果。
4. 如果表现与机制验证冲突，优先保留机制，不增加无关系统。
```
