# 离开前安排收益，回来后结算 · Set up earnings before leaving

> 离线收益取决于离开时的安排，也可能受到时间上限约束。

- **系统**：放置与增量（incremental）
- **标签**：time, planning, economy
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/incremental-offline-window/)

## 基础规则

玩家离开前选择持续执行的动作或产出配置。返回时按有效离线时长结算，耗材、容量或时间上限可能使后续时间不再产生同等收益。下一次离开前，玩家会依据停工原因重新准备。

## 核心循环

1. 查看本次要离开多久
2. 选择可持续执行的安排
3. 回来查看离线结算
4. 补足限制再安排下一次

## 关键取舍

- 离开很久时，选择收益高但很快耗尽材料的任务，还是低收益却能持续的任务？
- 先提高产出速度，还是先延长有效离线时间？

## 可调参数

- **有效离线时长**：上限越短，配置与实际离开时间越容易不匹配；应清楚显示何时停止结算。
- **离线效率**：与在线相同便于理解；不同时应同时显示速率和损失原因。

## 最小原型

- **第一步**：保存退出时间与一种任务，返回时结算带上限的时间差，并展示计算明细。
- **验证**：玩家能否从结算报告解释为什么少赚了一部分？
- **避免**：设备时间变化、重复结算和材料不足都要有确定规则。
