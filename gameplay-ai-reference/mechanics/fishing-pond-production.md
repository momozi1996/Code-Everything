# 鱼塘繁育 · Fish-pond production

> 把一次成功捕获，转化为持续繁育的生产起点。

- **系统**：钓鱼与捕捉（fishing）
- **标签**：economy, progression, planning
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/fishing-pond-production/)

## 基础规则

玩家把捕获的鱼放入鱼塘，等待繁殖或收集鱼卵，再决定提取多少存量。鱼塘空间有限，保留繁殖基础与立即出售之间存在取舍；不同鱼种改变产出价值。

## 核心循环

1. 捕获并选择种鱼
2. 建塘并放入鱼
3. 等待繁殖或产卵
4. 收获并保留生产基础

## 关键取舍

- 稀有鱼直接出售能回笼资金，留下繁殖则可能带来长期收益。
- 每个鱼塘投入哪种鱼，会锁定土地和后续维护方向。

## 可调参数

- **繁殖速度**：慢繁殖强调保护种群，快繁殖容易转成大规模流水线。
- **容量扩张条件**：材料任务增加阶段目标，纯付费升级则更侧重资本积累。

## 最小原型

- **第一步**：做一个有容量上限的鱼塘、繁育计时和“取出几条”的选择，先只用一种鱼。
- **验证**：遇到紧急订单时，玩家是否理解抽空鱼塘会损失后续收益？
- **避免**：别把完整遗传、疾病与多鱼种生态一起塞入第一版；先测试提取与保留的平衡。
