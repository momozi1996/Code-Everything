# 无限递归房间

```
Build "Droste — The Infinite Room", an endless-zoom artwork: a self-similar scene that zooms forever — a room with a framed picture on the wall that contains the same room, which contains the picture… Render on canvas by drawing the scene recursively at successive scales (each level scaled by the frame ratio), animating the zoom continuously and wrapping seamlessly each time a full level is reached. The room is illustrated in a flat, elegant mid-century-modern style: warm walls (#f1dac4), a teal armchair (#2a9d8f), a mustard lamp (#e9c46a), a geometric rug, a window with a changing sky and a plant; the framed painting is the recursion portal. Each depth level shifts the palette subtly so the journey feels alive. Interaction: scroll/pinch controls zoom speed and direction (zooming out is infinite too); click to switch scenes ("Room", "Spiral staircase" with an Escher-like spiral, "Ocean window"); pause; and a "Droste twist" toggle that applies a logarithmic-spiral (conformal) transform for the famous Droste spiral effect. Typography: tiny modernist sans captions.
```
