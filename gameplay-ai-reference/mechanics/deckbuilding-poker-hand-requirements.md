# 凑牌型来支付行动 · Using card patterns as action requirements

> 同一手扑克可以凑成不同组合，用哪一组决定你能做什么。

- **系统**：卡组构筑（deckbuilding）
- **标签**：planning, randomness
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/deckbuilding-poker-hand-requirements/)

## 基础规则

行动或得分要求由对子、同花、连续数字等牌型定义，玩家从手牌中选出满足条件的一组。使用这些牌后，可留给其他行动的组合会改变，因此强牌型不一定总是最合适。

## 核心循环

1. 观察手牌关系
2. 列出可达成的牌型
3. 按目标分配牌组
4. 更新剩余组合

## 关键取舍

- 用对子完成眼前的小收益，还是消耗更多牌去凑更强效果？
- 同一张牌能补两种组合，把它给攻击还是防守？

## 可调参数

- **牌型条件难度**：条件越难，成功越有成就感，但需要更多抽牌或修牌支持。
- **小牌型保底收益**：给普通组合可靠用途，能减少坏手牌直接失去一回合。

## 最小原型

- **第一步**：只用两种花色和对子、三张同花两个条件，配一个攻击和一个防守行动。
- **验证**：玩家能发现一张牌被多个组合争用，并选择牺牲其中一个。
- **避免**：别急着实现全部扑克牌型；先保证界面能解释为什么一组牌合法。
