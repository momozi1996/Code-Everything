# 探索换取地图信息 · Earned map information

> 地图不是开局全知，而是需要主动获取的探索成果。

- **系统**：探索与路线（exploration）
- **标签**：information, discovery, planning
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/exploration-earned-map/)

## 基础规则

玩家先在不完整信息下移动，再通过寻找地图、测绘或据点更新获得区域信息。地图降低重复迷路成本，却保留未探索支路；信息获取本身成为有价值的目标。

## 核心循环

1. 在未知区域辨认地标
2. 寻找地图或记录条件
3. 更新已知空间
4. 据此选择新路线

## 关键取舍

- 先绕路补地图，还是带着不确定性直接深入？
- 已经知道主路后，还要不要为未标明的支路消耗补给？

## 可调参数

- **更新时机**：实时更新方便导航，回到据点才更新会强调记忆与风险。
- **信息粒度**：只给地形保留观察空间，连奖励都标注则偏向任务清单。

## 最小原型

- **第一步**：做六个房间的地图、未发现遮罩和一个能揭示区域的节点。
- **验证**：比较获得地图前后的路线，观察玩家是否减少重复迷路又继续探索支路。
- **避免**：地图一次揭示全部奖励会削弱现场观察；先区分路线信息与秘密信息。
