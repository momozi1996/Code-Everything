## Prompt

```
Build "Rule 30 — Tapestries of Elementary Cellular Automata". Explore all 256 Wolfram elementary cellular-automaton rules rendered as woven textiles: each cell is a small woven block with warp/weft shading, so Rule 30's chaos, Rule 90's Sierpiński triangles and Rule 110's structures read as jacquard fabric. Palette sets: "Kilim" (madder red #a4161a, indigo #1b263b, saffron #f4a300, cream #f1e9da), "Monochrome linen" and "Neon loom". The rule is displayed as its eight neighbourhood patterns → output, each clickable to toggle a bit, building a custom rule number live. The tapestry scrolls continuously upward as new rows are generated (like a loom producing cloth), with a shuttle illustration moving across. Controls: rule number input/slider, random or single-cell start, speed, palette, and "famous rules" chips (30, 90, 110, 184, 150, 45, 73). Hovering the tapestry shows the rule applied at that cell. Typography: a textile-label serif with monospace numbers.
```
