# 推箱与不可逆走位 · Box pushing and positional traps

> 移动物体之前，先想好自己还能站在哪里。

- **系统**：解谜与推理（puzzles）
- **标签**：spatial, planning, information
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/puzzles-box-pushing/)

## 基础规则

玩家从相邻格推动箱子，通过位置变化打开路径或满足目标。推动后可能无法走到反方向，也可能把物体卡入死角，因此解题关注站位与操作顺序；撤销帮助验证方案。

## 核心循环

1. 辨认目标与死角
2. 规划可站立位置
3. 按顺序推动箱子
4. 检查目标或撤销

## 关键取舍

- 先解决远处目标，还是先腾出操作通道？
- 当前动作是否保留反向推动的站位？

## 可调参数

- **撤销范围**：无限撤销鼓励推理实验；有限撤销增加执行压力。
- **箱子特殊性质**：少量例外可扩展解法；太多例外削弱可读性。

## 最小原型

- **第一步**：做一张小格子地图、两个箱子、两个目标与逐步撤销。
- **验证**：观察玩家是否会提前保留站位，能否说出把箱子推入死角的后果。
- **避免**：先手工验证谜题有解；多加箱子只会增加搜索量，不保证更多好决策。
