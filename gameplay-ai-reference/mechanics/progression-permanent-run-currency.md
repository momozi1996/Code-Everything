# 失败也能带回成长资源 · Persistent currency between attempts

> 这一趟没通关，也能为下一趟留下可用的提升。

- **系统**：成长与解锁（progression）
- **标签**：progression, economy, risk
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/progression-permanent-run-currency/)

## 基础规则

每次尝试中获得一种能跨局保留的资源，结束后用它购买长期提升。玩家在单次成功之外还有一个较小目标：把资源转成下一次更好的起点；局内临时收益要与永久资源清楚区分。

## 核心循环

1. 进入一次挑战
2. 积累可保留资源
3. 结束后购买长期提升
4. 带着新起点再试

## 关键取舍

- 这次争取过关，还是走更容易拿成长资源的路线？
- 买便宜的即时提升，还是攒钱等待能改变打法的大升级？

## 可调参数

- **失败时保留比例**：保留越多，失败越少白费；太高也可能让快速送死变得划算。
- **升级对起点的影响**：提升过大，会让前期挑战变成重复劳动；提升过小又难感到进步。

## 最小原型

- **第一步**：做一个短关卡、一种跨局资源和两个永久升级；失败后直接进入购买页。
- **验证**：失败后玩家是否能说出本次留下了什么，并主动选择下一次目标？
- **避免**：先别做无限升级；避免玩家必须刷很多次才能体验基础操作。
