# 多级生产链 · Multi-stage production chains

> 把上一道工序的产出变成下一道的输入，逐级制造复杂物品。

- **系统**：自动化与物流（automation）
- **标签**：planning, progression, optimization
- **出处**：[Gameplay Atlas](https://gameplayatlas.loopyhop.com/mechanic/automation-production-chain/)

## 基础规则

玩家从最终产品倒推中间材料，配置机器配方并连接供料。任何前置缺失都会让后段停机；产线完成后可持续输出目标产品。

## 核心循环

1. 选定目标产品
2. 拆解配方依赖
3. 建设前后工序
4. 试产并补齐短板

## 关键取舍

- 集中生产通用零件便于复用，但会形成共享瓶颈。
- 提前扩建上游有余量，却占用眼前稀缺的材料。

## 可调参数

- **依赖深度**：层级增多会放大规划感，也增加定位停机原因的难度。
- **中间品复用率**：复用越高，局部扩产越容易影响其他产品。

## 最小原型

- **第一步**：先做矿石→铁板→齿轮三步，每步一种机器，显示输入缺口和每轮产量。
- **验证**：当最终机器断料时，玩家是否沿依赖关系追到真正短缺的上游环节？
- **避免**：配方树、物流和机器速度会互相放大调试成本，先固定其中两项再改第三项。
