## Prompt

```
第一版：帮我制作一个动画，主题描绘我们app 的理念和设计以及买点；包括音效和音乐；你可以使用任何你觉得合适的工具和技术，做出最好最惊艳的效果，不要使用已有的skill，不要参考以前做过的视频或者文案

第二版（改进）：我觉得开头动画很不错，真实渲染也接近还原了。只是，少一些真实的使用交互过程，app在手机端能做的事也不够细，比如git管理，文件预览管理，图片插入终端，等等等等，要让人看了能学习到app是如何使用的，有哪些便利化的或者可以做到的事让它们不用去碰桌面的电脑躺着开发。另外rust终端的性能数值不用给，给一个倍数更好，不同的设备差异不一样，平均下来提速2-4倍，带来的好处是什么，比如超长会话上下文也能稳定运行不会崩，内存管理好等等。以及除了开头和结尾的动画，期间的背景啊风格啊有点ai味道审美丢掉了，要把审美捡起来。打磨每一个细节
```
