## Prompt

```
请用原生 JavaScript 与 Canvas2D 制作原创双人浏览器游戏「霓虹气垫球」。画布 960×600，深蓝球场、青绿与粉红球拍、发光冰球、网格地板、圆形开球区、球门网、碰撞粒子与短拖尾。P1 用 WASD/F/G，P2 用方向键/K/L；方向移动，主动作短冲刺，副动作精确慢移。每人限于自己半场，使用圆形球拍和圆形冰球的真实碰撞，球拍移动速度传给球，边墙反弹，左右球门进球计分。每局 60 秒或率先 7 球，平局真实显示。提供可重置固定种子、普通输入驱动的机器人、暂停、音效开关与移动端双人按键。禁止脚本预设输赢。编写半场边界、球门/边墙区分、碰撞反弹、冲刺、胜利冻结、确定性测试。
```
