# 从例题归纳视觉规则 · AI 原型任务模板

> 来源：https://gameplayatlas.loopyhop.com/mechanic/puzzles-visual-rule-learning/

```text
你是一名资深游戏原型工程师。请用原创代码与原创占位素材，实现一个可玩的最小原型，验证以下机制。不要复制任何现有游戏的名称、角色、世界观、地图、界面布局、数值表、美术、音频或代码。

## 机制
从例题归纳视觉规则（Inferring visual puzzle rules）

## 设计目标
不用说明书，让玩家从反馈中自己学会语法。

## 基础规则
玩家面对统一输入界面和逐步变化的符号，先从简单题猜测规则，再用复杂题验证。错误说明当前组合不满足条件，玩家需要比较题目并修正假设，而不是盲目尝试。

## 核心循环
1. 比较简单样例
2. 提出规则假设
3. 在新题中验证
4. 用反例修正规则

## 关键取舍
- 哪个差异改变答案，哪些只是视觉装饰？
- 假设能解释所有已解题，还是只碰巧通过上一题？

## 可调参数
- 示例排序：先隔离再组合规则可降低误学；过早混合增加负担。
- 错误反馈：指出错误位置更友善；只给成败要求更强归纳。

## 最小实现建议
设计一条清晰规则、四道教学例题和两道会排除错误假设的题。

## 验证方式
不解释规则，让玩家用自己的话描述它，再解一道没见过的新题。

## 需要避免
关键成本在题目安排；规则复杂却没有辨别线索，只会变成猜答案。

## 交付要求
1. 先完成可验证的机制闭环，再考虑表现层；范围控制在单局 3–5 分钟。
2. 所有素材必须原创、程序化生成或使用明确的占位符，不使用第三方游戏资产。
3. 提供运行方式、操作说明、关键参数和验证结果。
4. 如果表现与机制验证冲突，优先保留机制，不增加无关系统。
```
