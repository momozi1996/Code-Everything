## Prompt

```
把文件中的这张参考图做成 SVG，并给出一个完整的视频或者动画录制，让我看到它的绘制过程。

要求：

SVG 越精细越好。
绘制元素在 1500–1700 之间。
注意，在绘制 SVG 时，尽量模拟人类绘画时的流程：

画草稿，确定大形和比例
铺大色块，建立明暗关系
逐步细化结构、光影和细节
检查整体，调整收尾
绘制方式：

根据当前画面，分批决定接下来画什么。
在绘制过程中修改比例、轮廓和连接关系。
观察和修改贯穿全过程，不是等画完才修正。
```
