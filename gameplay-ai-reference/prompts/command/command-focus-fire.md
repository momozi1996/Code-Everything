# 集中火力先减掉一个威胁 · AI 原型任务模板

> 来源：https://gameplayatlas.loopyhop.com/mechanic/command-focus-fire/

```text
你是一名资深游戏原型工程师。请用原创代码与原创占位素材，实现一个可玩的最小原型，验证以下机制。不要复制任何现有游戏的名称、角色、世界观、地图、界面布局、数值表、美术、音频或代码。

## 机制
集中火力先减掉一个威胁（Focus fire to remove one threat）

## 设计目标
打伤所有敌人，与让一个敌人停止攻击，是两种收益。

## 基础规则
玩家让多个单位攻击同一目标，争取先让它失去战斗能力，减少敌方持续输出。集中火力也可能让剩余伤害溢出、远程弹丸浪费或其他威胁无人处理，因此需要及时换目标。

## 核心循环
1. 挑选优先消灭的目标
2. 让多个单位共同攻击
3. 确认击倒与剩余伤害
4. 转向下一个威胁

## 关键取舍
- 先杀脆弱输出者，还是先处理正在突破防线的重甲者？
- 还有弹丸在飞，是否提前切换目标避免溢出？

## 可调参数
- 过量伤害浪费：高单发伤害会提高分配最后一击的价值。
- 目标切换成本：切换会移动或重置准备时，需要预先规划顺序。

## 最小实现建议
三名友方、两名敌人，显示血量与即将落下的伤害。

## 验证方式
玩家是否能解释为何集中攻击比平均削血更合适，何时又该分火？

## 需要避免
命中与弹道如果不透明，玩家难以判断何时换目标。

## 交付要求
1. 先完成可验证的机制闭环，再考虑表现层；范围控制在单局 3–5 分钟。
2. 所有素材必须原创、程序化生成或使用明确的占位符，不使用第三方游戏资产。
3. 提供运行方式、操作说明、关键参数和验证结果。
4. 如果表现与机制验证冲突，优先保留机制，不增加无关系统。
```
